# v2: quasi-floating-gate threshold-logic / p-bit cell (SKY130)

Everything in the IOP manuscript (`paper_iop/`) is regenerated by the scripts in this folder,
`layout/v2/` and `layout/v2/openroad/`. All tools are open source.

## Toolchain

| Tool | Version used | Purpose |
|---|---|---|
| ngspice | 45 | circuit simulation (SKY130 BSIM4 models) |
| Magic | 8.3.681 | layout, DRC, extraction |
| Netgen | 1.5.323 | LVS |
| KLayout | 0.30.7 | independent DRC (FEOL+BEOL+grid), rendering |
| Yosys | 0.62 | synthesis of standard-cell baselines |
| OpenROAD | 2026-02-17 | place & route, STA, power of baselines |
| SKY130 PDK | volare `c6d73a35f524070e85faff4a6a9eef49553ebc2b` | models, rule decks, std cells |

`source .eda/env.sh` puts the tools (installed with nix) and the PDK (`.eda/pdk`, installed with volare)
on the path. The `.eda/` folder is not version-controlled.

## Notes and pitfalls found along the way

* SKY130 `.lib` sections reset `mc_mm_switch=0`; set it **after** the `.lib` line and use
  `.option seed=N` (parse-time) to get independent mismatch draws.
* ngspice sub-circuit names are case-insensitive: the extracted `qfg_tlg` is renamed to
  `qfg_tlg_pex` before the `QFG_TLG` wrapper is defined (`ngs.pex_cell_text`).
* The reset switch's junction leakage only appears in the extracted netlist, because schematic
  devices have no AD/AS. Retention therefore uses the extracted cell.
* Magic's capm halo rule (no unrelated metal3 within 1.34 µm of a MIM top plate) and KLayout's
  capm.11 rule (metal2 ≥ 0.14 µm from capm) drive the floorplan.
* v1.0 bug: `tb.py` drove the inputs with a fixed 1.8 V amplitude, so the SS (1.60 V) and FF (1.95 V)
  windows were wrong. v1.1 uses the corner supply; all SS/FF numbers were regenerated.
* The full-adder sum is non-monotonic (it pulses high before the inverted carry arrives); `fa.py`
  reports settling times, not first crossings.
